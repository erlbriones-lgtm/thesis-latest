# Project Guidelines & Rules

## Tech Stack & Language Consistency
- **Strict Language & Stack Rule**: Strictly use only the existing language and technology stack of this project. Do not introduce other frameworks, libraries, or programming languages.
  - **Programming Language**: Vanilla JavaScript (ES Modules, standard `.js`)
  - **Markup & Templates**: Standard HTML (`index.html`, component HTML files in `components/` using Vite compile-time include tags)
  - **Styling**: Tailwind CSS and custom CSS in `css/` & `style.css`
  - **Backend Client**: Supabase JavaScript client (`@supabase/supabase-js`)
  - **Spoken / UI Language**: English (as used throughout the BISU Calape Feedback System)
